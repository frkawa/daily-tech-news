### ★★★★☆ [Claude Code の /ship を図解する](https://zenn.dev/peoplex_blog/articles/claude-code-ship) `ai` `github` `pullrequest` `claude` `claudecode`

- Claude Code の /ship スキルは PR 作成からマージ直前までを 1 セッションで管理し、最長 7 日間 PR を監視する。CI 失敗やコメント時のみ Claude が起動するため、使用量が効率的。
- /ship は権限のある人のコメントのみ対応し、push は同一原因で 3 回まで、使用可能コマンドも制限されるなど、セキュリティと信頼性が組み込まれている。
- 従来は複数のスキルや手作業で繋いでいた開発フローを統一でき、マージは人が実行する設計で、開発者の手作業を大幅に削減できる。

**Rubyistへの影響:** Ruby on Rails 開発における PR から マージまでの自動化フローが実現でき、開発効率向上と品質管理が同時に強化される。
